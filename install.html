Wi-Fi ছাড়া ব্যবহারের জন্য পেজ ও বাংলা ফন্ট অ্যাপের ভেতরেই আছে। Android 6 বা পরের সংস্করণ এবং Classic Bluetooth SPP প্রিন্টার প্রয়োজন।

Android APK ডাউনলোড করুন
  1. WhatsApp / Facebook-এর ভেতরের ব্রাউজার হলে মেনু থেকে Open in Chrome করুন।
  2. ডাউনলোডের পরে Chrome → Downloads অথবা ফোনের Files থেকে Emrul-Invoice-v1.1.apk খুলুন। GitHub-এর blob পেজ ইনস্টলার নয়।
  3. ফোন এই উৎস থেকে ইনস্টল করার অনুমতি চাইলে নিজের ডাউনলোড করা ফাইলটি যাচাই করে অনুমতি দিন।
  4. Play Protect স্ক্যান করতে বললে স্ক্যান করুন। ব্লক থাকলে স্ক্রিনের কারণটি দেখুন; APK ডাউনলোড হওয়া মানেই Android ইনস্টলের অনুমোদন নয়।

এটি signed release APK; Google Play-এর যাচাইকৃত প্রকাশনা নয়। Play Protect অপরিচিত developer-এর অ্যাপ আটকাতে পারে। নতুন release বানালেই সেই সিদ্ধান্ত উঠে যাবে—এমন নিশ্চয়তা নেই।

আগের debug অ্যাপ ইনস্টল করা থাকলে release-এর signing certificate আলাদা হওয়ায় আপডেট নাও হতে পারে। ইতিহাস থাকলে backup ছাড়া পুরোনো অ্যাপ uninstall বা data clear করবেন না।

Chrome দিয়ে ওয়েব অ্যাপ

ওয়েব পেজ খুলে Chrome মেনু → Add to Home screen / Install app ব্যবহার করুন। প্রথমবার ফাইলগুলো লোড হলে পরে অফলাইনেও খোলা যাবে। এটি Android APK ইনস্টল করার প্রয়োজন ছাড়াই ব্যবহার করা যায়।

ইনভয়েস পেজ খুলুন
